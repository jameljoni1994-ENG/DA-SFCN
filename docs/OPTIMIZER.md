## 1. الرؤية

أن تصبح عائلة **DA-SFCN** (ونيوتن التكعيبي الخالي من السرج ذو البعد الديناميكي) مرجعًا عالميًا في التحسين من الرتبة الثانية غير المحدب، بمعنى:

| اليوم | الهدف المرجعي |
|--------|----------------|
| أوراق EN/AR + تجارب لابتوب | مكتبة مرجعية قابلة للتثبيت والاستشهاد |
| مقارنات داخلية محدودة | جداول عادلة مقابل AdamW / L-BFGS / Krylov-CRN / SFN / Sophia (حيث يناسب العتاد) |
| بروتوكول تجريبي في الورقة | أمر إعادة إنتاج واحد + بذور موثّقة |
| أفكار امتدادات في الخاتمة | مساهمات مُتتبَّعة بحالة وأولوية وحمل جهاز |

النجاح ليس بعدد النجوم وحده، بل بإعادة إنتاج النتائج، ووضوح الـ API، وصلاحية المقارنة العلمية.

## 2. قيود الجهاز (ثابتة — اقرأ قبل أي تنفيذ لاحق)

هذه القواعد تحمي اللابتوب المحلي وتُدرج في كل اقتراح:

1. **لا GPU ثقيل محليًا** كافتراض؛ CPU + NumPy/SciPy هو المسار الافتراضي.
2. **المقياس الأساسي = عدد HVP** (وجداءات التدرّج)، لا زمن الجدار alone.
3. **أبعاد محلية:** استهدف `n` صغير–متوسط (تقريبًا `n ≤ 200`) وعدد عينات معتدل؛ لا ترفع الميزانية دون سبب.
4. **LLM / CIFAR الكامل / ضبط نماذج لغة واسعة = سحابة أو جهاز أقوى فقط** — يُوثَّق هنا كوصفة، لا يُشغَّل على الجهاز الضعيف.
5. **تجارب قصيرة أثناء التطوير:** smoke tests بالثواني–دقائق؛ إعادة توليد كل الأشكال اختياري وعند الطلب.
6. **لا تجارب متوازية تُنهك الذاكرة**؛ بذرة واحدة أو بضع بذور أولًا.
7. أي إطار جديد (مثل PyTorch) يُضاف لاحقًا كمسار **اختياري** ومعطّل افتراضيًا إن كان ثقيل التثبيت.

**وسوم الحمل المستخدمة أدناه:**

| الوسم | المعنى |
|--------|--------|
| خفيف | دقائق أو أقل؛ NumPy فقط؛ آمن محليًا |
| متوسط | عشرات الدقائق؛ بيانات أكبر قليلًا؛ راقب الذاكرة |
| ثقيل | ساعات / GPU / نماذج كبيرة — سحابة أو تأجيل |

## 3. تشخيص الفجوة (وضع المشروع الحالي)

إشارات مرجعية فقط لملفات موجودة (لا تعديلها من هذا الدفتر):

| المحور | الموجود الآن | الفجوة لمرجع عالمي |
|--------|----------------|---------------------|
| نظرية | معدل عالمي `O(k^{-2/3})` + تقارب محلي لوغاريتمي في الورقة الجامعة | إثباتات أنظف لـ LK / Fed تحت انحراف العملاء؛ preconditioned Lanczos |
| برمجيات | حزمة `dasfcn/` + `run_experiments.py` | `pyproject.toml`، واجهة موحّدة، اختبارات، ترخيص صريح، CITATION |
| معايير | سروج تحليلية، روزنبروك، لوجستي اصطناعي، تحليل مصفوفات | بذور متعددة، LIBSVM حقيقية، فاصل ثقة لهروب السرج، معيار HVP موحّد |
| تعلم عميق | مذكور كـ L5 في الورقة | خلفية autograd؛ نماذج صغيرة أولًا؛ LLM لاحقًا على سحابة |
| مجتمع | README + PDFs على GitHub | CONTRIBUTING، أمثلة Colab، جاهزية PyPI |

نقاط قوة حالية يمكن البناء عليها: عائلة خوارزميات متماسكة (DA-SFCN، VR، LK، WQK، Fed، SC)، أوراق ثنائية اللغة، تجارب هروب سرج قوية مقابل GD.
