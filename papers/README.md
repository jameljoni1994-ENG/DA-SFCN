# Papers

- `unified/` — full English and Arabic monographs covering the whole DA-SFCN family.
- `en/` — six English papers (one algorithm each).
- `ar/` — six Arabic papers (one algorithm each).
- `refs.bib` — shared bibliography.

Compiled PDFs are published in [`../pdfs/`](../pdfs/). Rebuild with:

```powershell
powershell -ExecutionPolicy Bypass -File ../scripts/compile_papers.ps1
```
